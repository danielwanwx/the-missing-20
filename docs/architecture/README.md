# Architecture Documents

- [`as-built-architecture.md`](as-built-architecture.md) is the current implementation
  diagram and the only architecture document used by the public README.
- `the-missing-20-architecture-v4.2.*` is a historical target-design exploration. It
  contains components that are not implemented and must not be used as evidence of the
  current product.

When the two disagree, the as-built architecture and persisted verification artifacts
are authoritative.
